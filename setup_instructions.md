1. Create Firebase project + get credentials
2. Create .env file with those credentials
3. Install Node.js (nodejs.org)
4. git clone (https://github.com/subbu-h21/payment_notifier_local_server_files.git)
5. Copy .env into  payment_notifier_final_local_server_file\package\local_server_file\
6. Double-click install.bat
7. Double-click start.bat  (or add start-silent.vbs to Startup folder)
